# Income Calculator
## Overview
A web-based income calculator designed to help mortgage and lending professionals calculate qualifying income across multiple different income types.

## Project Goals
This project is to help the professionals at Grand Line Lending calculate income faster and more effiecently. 

The second goal of this project is to build this website from scratch to work on my developing skills. Focusing on:
- HTML
- CSS
- JavaScript
- Git and GitHub
- GitHub Pages deployment
- Software project organization

## Features
Planned Calculators:
- Schedule C
- Partnership 1065
- S Corp 1120S
- Corporation 1120
- Variable Income
- Rental Income
- SSI Gross Up
